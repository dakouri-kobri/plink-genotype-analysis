# Genotype analysis with PLINK

This project was completed as part of the course of [Genome analysis BK0003 HT2026, 15 ECT credits](https://www.slu.se/en/student-web/studies/courses-and-programmes/course-search/kurser/g/genome-analysis/), at SLU (Swedish University of Agricultural Sciences), Uppsala, Sweden, autumn 2026. It represents my solutions to the exercises of one of the computer exercise sessions, genotype analysis with PLINK. The analyses and interpretations are presented in a single Quarto document, using R to run PLINK and display the results. R package dependencies are managed with renv.

## Topics

- Genotype file formats and allele frequencies
- Case/control association and Fisher’s exact tests
- Transmission disequilibrium tests (TDT)
- Linkage disequilibrium (LD)
- Missing data and quality control
- Hardy–Weinberg equilibrium
- Pedigree construction and Mendelian error detection

## Tools and package

- R and RStudio
- Quarto
- PLINK 1.9, available on the system PATH

R package dependencies are managed with renv.
